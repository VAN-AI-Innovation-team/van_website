# VAN Website

AI와 데이터를 기반으로 금융투자와 보건의료 분야의 변화를 연구하는 VAN의 공식 웹사이트입니다.

## 웹사이트 요약

VAN의 소개, 부서, 활동 기록을 한곳에서 확인할 수 있는 반응형 웹사이트입니다.

메인 화면에는 AI·금융·보건의료를 표현한 전체 화면 배경을 적용했습니다. 화면을 아래로 스크롤하면 배경 이미지가 자연스럽게 사라집니다.

## 페이지 구성

### 홈

- VAN의 핵심 메시지와 운영 원칙 소개
- 네 개 부서 미리보기
- AI 활용 절차 안내
- 최근 활동과 소식 표시

### VAN 소개

- VAN의 비전과 목표
- 운영 원칙
- 조직과 부서 구성
- 2022년부터 2025년까지의 연혁

### 부서 소개

- AI혁신부
- 금융투자리서치부
- 보건의료언론부
- 대외협력부
- 각 부서의 역할과 주요 활동 안내

### 소식·아카이브

- 행사, 프로젝트, 미디어, 언론보도 목록
- 분류별 필터 기능
- 실제 자료로 교체할 수 있는 데이터 구조

## 핵심 기능

- 전체 화면 대표 배경과 스크롤 페이드 효과
- 데스크톱·태블릿·모바일 반응형 화면
- 모바일 내비게이션
- 아카이브 분류 필터
- 키보드 접근성과 모션 감소 설정 지원
- 페이지 제목, 설명, 파비콘 등 기본 검색 노출 설정
- 화면과 콘텐츠 데이터를 분리한 구조

## 기술 구성

- React
- Vite
- React Router
- Zustand
- CSS
