# 관리자 프론트 초안

`/admin/`에서 한국어·영어 홈페이지, 후원 페이지, 모집 페이지의 주요 문구 20개를 편집할 수 있습니다. `초안 저장 · 미리보기`를 누르면 현재 브라우저의 `localStorage`에 저장하고 오른쪽 미리보기에서 확인합니다. 페이지 선택으로 세 페이지를 바꿀 수 있고, JSON 내보내기로 변경값을 파일로 받을 수 있습니다.

이 화면은 프론트 작업 범위입니다. 관리자 인증·권한, 서버 저장, 이미지 업로드, 공개 배포는 연결되지 않았습니다. 공개 페이지는 기존 정적 콘텐츠를 사용합니다. 미리보기 URL의 `?content-preview=1`이 있을 때만 현재 브라우저의 초안을 화면에 입힙니다. 따라서 다른 방문자에게는 초안이 보이지 않고, 공유한 URL만으로 초안이 전달되지도 않습니다. 실제 운영 관리자 화면으로 사용하려면 인증된 저장 API와 발행 절차를 먼저 연결해야 합니다.

## 파일 구조

- `src/pages/admin/index.astro`: 관리자 화면과 미리보기 영역
- `src/scripts/admin-editor.js`: 필드 렌더링, 입력 검증, 저장·초기화·내보내기
- `src/features/content/editor-model.js`: 언어별 기본값과 편집 가능한 필드 목록
- `src/features/content/content-store.js`: 브라우저 초안 저장 경계
- `src/features/content/content-preview.js`: 미리보기 URL에서만 초안 적용
- `src/features/platform/admin-modules.js`: 콘텐츠·회원·알림·AI·협력기관 관리자 메뉴 목록과 구현 상태

새 문구를 편집 대상으로 넣으려면 `EDITABLE_SECTIONS`에 필드를 추가하고, 실제 페이지의 해당 텍스트 요소에 같은 키의 `data-content-key`를 지정합니다. 변경할 수 있는 값은 현재 문자열 필드입니다. 링크 URL, 이미지, 목록·카드의 추가·삭제처럼 화면 구조나 안전성 검토가 필요한 항목은 별도 편집 유형으로 확장해야 합니다.

회원·알림·AI·협력기관 메뉴는 향후 기능의 자리만 표시하며 기능이 구현된 것처럼 연결하지 않습니다. 각 기능은 `src/features/<기능>/`에 UI·데이터 접근 코드를 두고, 고유 관리자 라우트를 만든 뒤 `ADMIN_MODULES`의 상태를 `ready`로 바꿉니다. 서버 API 연결 시에는 `content-store.js` 경계에 인증된 읽기·저장 구현을 추가하고, 발행된 콘텐츠를 정적 빌드에 공급하거나 공개 페이지에서 조회하는 방식을 결정해야 합니다. 인증과 권한 검사는 반드시 서버에서 수행해야 합니다.
